# Developer and Agent Instructions for BitBytes

## Engineering Guidelines
- **Minimalist Architecture:** Avoid superfluous libraries, deep abstractions, and unnecessary dependencies. Prefer native language features and standard web APIs.
- **Diff Discipline:** Keep pull requests and edits focused, small, and well-tested. Remove dead code whenever refactoring.
- **Accessible UI:** Ensure semantic HTML, visible focus states, WCAG AA color contrast, and respect for `prefers-reduced-motion`.
- **Quality & Performance:** Strive for fast load times and clean client bundles without external network font dependencies.
