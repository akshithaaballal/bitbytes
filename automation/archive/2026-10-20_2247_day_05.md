# TCP vs UDP: 3-Way Handshake vs Blazing Speed
> **Track:** Computer Networks | **Day:** Friday | **Date:** 2026-10-20

**Understanding the transport layer powering the internet**

## 📌 Overview
TCP guarantees reliable, ordered packet delivery with flow and congestion control. UDP prioritizes minimum latency with zero handshake overhead.

## 💡 Key Highlights
- TCP (Reliable): 3-Way Handshake (SYN -> SYN-ACK -> ACK). Resends lost packets. Best for HTTP/HTTPS, WebSockets, File Downloads.
- UDP (Speed): Connectionless, fire-and-forget. Packet loss is tolerated for low-latency streaming. Best for Video Calls (WebRTC), Gaming, DNS, VoIP.
- QUIC & HTTP/3: Modern breakthrough! Runs on top of UDP to eliminate Head-of-Line blocking while maintaining TCP-level encryption and reliability.

## 💻 Code Example
```python
# Python UDP Socket Client (Zero Handshake)
import socket

client = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
client.sendto(b"Telemetry Ping", ("127.0.0.1", 9999))
# No connection established; sent directly over the wire!
```

## ⚡ Complexity & Performance
- **Header Size:** `TCP (20-60 bytes) vs UDP (8 bytes fixed)`
- **Overhead:** `TCP has connection teardown (FIN/ACK); UDP has zero teardown`

## 🎯 Interview Tip
> [!TIP]
> When asked why YouTube or Netflix uses TCP instead of UDP: video streaming buffers chunks ahead of time via HTTP/TCP; live real-time video calls (Zoom/Meet) use UDP via WebRTC!
