# Mastering the Two-Pointer Technique
> **Track:** DSA Bite | **Day:** Monday | **Date:** 2026-10-11

**Solve sorted array problems in O(N) time with O(1) space**

## 📌 Overview
The Two-Pointer approach reduces brute-force O(N^2) pair searches to linear O(N) time by moving pointers inward or outward based on condition checks.

## 💡 Key Highlights
- Opposite Direction: One pointer at start (left = 0), another at end (right = n - 1).
- Condition: If sum < target -> left++; If sum > target -> right--; If sum == target -> match found!
- Classic Applications: Pair Sum, Container With Most Water, 3Sum, Valid Palindrome.

## 💻 Code Example
```python
def two_sum_sorted(arr, target):
    left, right = 0, len(arr) - 1
    while left < right:
        curr_sum = arr[left] + arr[right]
        if curr_sum == target:
            return (left, right)
        elif curr_sum < target:
            left += 1
        else:
            right -= 1
    return None
```

## ⚡ Complexity & Performance
- **Time:** `O(N) - single pass through array`
- **Space:** `O(1) - only two integer pointers`

## 🎯 Interview Tip
> [!TIP]
> Always check if the array is already sorted. If not, sorting takes O(N log N) - check if hashing (O(N) space) is better!
